#Linux and GIT Commands


##Linux Commands:  

1.ls - lists: used to list files and directories in current working directory.  
2.pwd - print working directory: used to display the full path of the current directory.  
3.mkdir - make directory: used to create new directories or folders.  
4.cd - change directory: used to change the current working directory.  
5.rmdir - remove empty directory: used to delete empty directories.    
6.cat - concatenate: used to display file contents and combine multiple files.    
7.cp - copy: used to copy files or directories.  
8.mv - move: used to remove or rename files and directories.  
9.rm -remove files or directories: used to delete files permanently.    
10.touch - used to create empty files and update files.  

##GIT Commands:  
1.git init -Initializes a new, empty Git repository in the current folder.  
2.git status -Shows which files are modified, staged, or untracked.  
3.git branch -Lists all local branches.  
4.git pull -Downloads changes and immediately merges them (Fetch + Merge).  
5.git fetch -Downloads changes from the remote but does not update your code.
